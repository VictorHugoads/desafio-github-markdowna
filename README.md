>> DESAFIO DE PROJETO <<
Olá, visitante 👽! Sejam bem-vindos(as)!
Estou muito feliz por você ter chegado até aqui e ter acompanhado a minha jornada de aprendizado. Através deste desafio, consegui testar tudo o que aprendi sobre o Git, GitHub, colaboração e a incrível linguagem Markdown 💞. Agora, vou compartilhar como completei cada etapa do desafio:

Objetivos:
1. Criar minha conta no Github:
Essa foi a primeira etapa para alcançar os objetivos do desafio. Criei minha conta no GitHub, que é essencial para seguir com os próximos passos.

2. Criar um Repositório:
Criei um novo repositório no GitHub, nomeando-o como "desafio-github-markdown".

Ao criar o repositório, adicionei automaticamente um arquivo README.md.

Utilizei o Github.dev para editar o projeto diretamente no editor web do GitHub.

Lembre-se, o repositório foi criado como público, conforme as instruções.

3. Colaboração:
Adicionei um colaborador ao repositório (neste caso, usei uma conta diferente minha).

Ambos fizemos o clone do repositório nas nossas máquinas locais.

Realizamos diversas alterações no repositório, fizemos Commits, abrimos issues e até criamos pull requests.

4. Formatação com Markdown:
Editei o arquivo README.md no repositório.

Utilize a linguagem Markdown para formatar o conteúdo, com informações sobre o desafio, instruções e uma breve descrição do meu projeto.
